# 黑雾工坊 DarkFogWorkshop

**用科学矩阵，自动化生产黑雾材料。**

不加配方，不加建筑，不改动任何原版数据 —— 只给已有的**物流运输站**加一条新产线。

---

## 功能生效方式

一座物流运输站满足以下条件时自动生效，无需任何额外操作：

1. **第 1 格**放入**科学矩阵**（电磁 / 能量 / 结构 / 信息 / 引力 / 宇宙，六种都行）；
2. 第 1 格设置为**本地需求**；
3. **第 2 格起**放入你想产出的**黑雾材料**，一格一种。

**触发条件是「第 1 格是科学矩阵」且「第 1 格设为本地需求」，两者缺一不可。**
没勾「本地需求」的塔，MOD 完全不会介入 —— 所以不会误伤你现有的星际物流塔。

可产出原版全部六种黑雾材料：能量碎片、黑雾矩阵、硅基神经元、负熵奇点、物质重组器、核心素。

## 生效后游戏内有提示

生效后，该物流塔配置窗口的**关闭按钮正下方会出现一个 `?`**。
**鼠标悬停**（不用点击）即弹出实时账本，显示这座塔当前的：

- 矩阵转化算力速度 `Y`
- 单种材料每分钟算力
- 第 1 格的**消耗速度**（单种 / 合计）
- 各产出槽位的**转化速度**（个/分钟）
- 全部物品的**算力对照表**

矩阵喷了增产剂时，提示框还会显示当前**增产等级**与**额外产出**比例。

## 算力算法

### 1. 每分钟算力

```text
每分钟算力 = U × Y
```

| 符号 | 含义 | 默认值 |
|---|---|---|
| `U` | 黑雾工坊初始算力（配置项 `MatrixPointPerMinute`） | `7200` |
| `Y` | 矩阵转化算力速度，默认直接取存档的**研究速度** | 存档决定 |

例：研究速度 400%（`Y = 4`）时，每分钟算力 = `7200 × 400% = 28800` 点。

> 升级「研究速度」科技会让 `Y` 上升，黑雾工坊产量**随之提高**。
> 可在配置中关闭联动，改为手工指定固定值。

### 2. 黑雾材料生成速率

**每种材料各占一份算力，互不抢占。** 单种材料的产出速率：

```text
单种材料生成速率（个/分钟） = 每分钟算力 ÷ 该材料算力
```

| 黑雾材料 | 算力 | 研究速度 400% 时 |
|---|---|---|
| 能量碎片 | 50 | 576 /分钟 |
| 黑雾矩阵 | 150 | 192 /分钟 |
| 硅基神经元 | 100 | 288 /分钟 |
| 负熵奇点 | 100 | 288 /分钟 |
| 物质重组器 | 100 | 288 /分钟 |
| 核心素 | 300 | 96 /分钟 |

### 3. 矩阵消耗速率

**放 N 种材料，就按 N 份算力消耗矩阵**：

```text
矩阵消耗速率（个/分钟） = 材料种数 × 每分钟算力 ÷ 该矩阵的算力
```

| 科学矩阵 | 算力 |
|---|---|
| 电磁矩阵 | 50 |
| 能量矩阵 | 100 |
| 结构矩阵 | 250 |
| 信息矩阵 | 750 |
| 引力矩阵 | 1500 |
| 宇宙矩阵 | 3000 |

**举例**：第 1 格放**电磁矩阵**（50），第 2~4 格放 3 种材料，研究速度 400%（每分钟算力 28800）：

```text
黑雾材料生成：每种 28800 ÷ 各自算力   （如能量碎片 576/分钟）
矩阵消耗    ：3 × 28800 ÷ 50 = 1728/分钟   （单种 576/分钟，三种合计 1728/分钟）
```

### 4. 增产剂加成

第 1 格的矩阵**喷过增产剂**时，同一份算力**多产出材料**，**矩阵消耗量不变**。
加成比例取自游戏自身的增产表（等级 1~10 为 +12.5% ~ +40%）。

等级判定沿用游戏规则：**累计增产点数 ÷ 物品数**（向下取整），
因此是**整栈的平均等级**。从塔中取走矩阵时，增产点数按引擎同样的算法等比扣减，**等级不会掉**。

### 5. 不浪费矩阵

材料槽位**全部填满**时，塔**不会继续扣矩阵** —— 不会出现堵料后矩阵白白消失。

## 参数高度可调

全部数值都在 `BepInEx\config\TTenYX.DSP.DarkFogWorkshop.cfg`，改完保存即可生效：

| 分区 | 能改什么 |
|---|---|
| `1. 通用` | 初始算力 `U`、兑换系数、是否联动研究速度、参与兑换的槽位上限 |
| `2. 科学矩阵算力` | 六种矩阵各自的算力权重 |
| `3. 黑雾材料算力` | 六种材料各自的算力权重 |
| `4. 界面` | 诊断日志开关 |

想让黑雾材料更贵、更便宜，或只让某几种材料参与兑换，都只需改数值，不必改代码。

## 与原版的契合度

| 项目 | 行为 |
|---|---|
| 配方 | **不新增、不修改**任何配方 |
| 建筑 | **不新增**任何建筑，复用原版物流运输站 |
| 塔名 | **不修改**（不会自动改名） |
| 耗电 | **不修改**物流塔耗电 |
| 统计面板 | 产出与消耗**正常计入** |
| 增产剂 | 沿用游戏原生机制与数值表 |
| 非目标塔 | 触发条件不满足的塔**完全不受影响** |

## 安装

1. 安装 **BepInEx 5**（x64）；
2. 把 `DarkFogWorkshop.dll` 放到 `BepInEx\plugins\`；
3. 启动游戏，物流塔配置窗口出现 `?` 即安装成功。

用 r2modman / Thunderstore Mod Manager 安装则无需手动操作。

需要 **BepInEx 5**，适配游戏 **0.10.35**。
