# DarkFogWorkshop 黑雾车间

作者：**TTenYX**

用物流塔把**科学矩阵**（玩家社区俗称"糖"）兑换成各种**黑雾材料**。

---

## 玩法

把一座物流塔配成"黑雾车间"：

| 槽位 | 放什么 | 设置 |
|---|---|---|
| 第 1 格 | 科学矩阵（电磁/能量/结构/信息/引力/宇宙矩阵） | 必须勾选**本地需求**（星际塔勾"本地需求"那一栏即可） |
| 第 2 格起 | 任意黑雾材料，可放多种 | 按需要设供应/需求 |

三个条件同时满足时，每帧消耗第 1 格的矩阵，并给**每一种**材料各自生成对应产出。

参与兑换的材料槽位默认到**第 4 格**；配置项 `OutputSlotLimit` 可以改（装了运输塔扩容后可调更大）。

可参与兑换的六种黑雾材料：

- 能量碎片
- 黑雾矩阵
- 硅基神经元
- 负熵奇点
- 物质重组器
- 核心素

> 物品 ID 取自游戏常量 `ItemProto.kDF*`：黑雾矩阵 5201、硅基神经元 5202、物质重组器 5203、
> 负熵奇点 5204、核心素 5205、能量碎片 5206。网上有些资料把 5202/5203/5205/5206 的对应关系写反了。

## 算力规则

```
每帧算力（每种材料各一份）= U × Y × SpeedMultiplier
矩阵点数                 = 矩阵算力 × 消耗个数
兑换一个黑雾材料          = X × 该材料算力
```

| 符号 | 含义 | 默认值 |
|---|---|---|
| `U` | 物流塔矩阵算力效率（`MatrixPointPerFrame`） | 100 |
| `Y` | 科技研究速度（`GameMain.history.techSpeed`，100 = 100%） | 100% |
| `X` | 兑换系数（`ExchangeFactor`），可小数 | 1 |

矩阵算力：电磁 50 / 能量 100 / 结构 250 / 信息 750 / 引力 1500 / 宇宙 3000

黑雾材料算力：能量碎片 50 / 黑雾矩阵 150 / 硅基神经元 100 / 负熵奇点 100 / 物质重组器 100 / 核心素 300

### 每种材料的速度相互独立

第 2 格起的每一种材料都**单独拿一份**每帧算力，互不挤占：

| 塔里的材料种数 | 每种材料的速率 | 矩阵消耗 |
|---|---|---|
| 1 种 | 1 倍速 | 1 倍 |
| 2 种 | 各自 1 倍速 | 2 倍 |
| 3 种 | 各自 1 倍速 | 3 倍 |

矩阵不够时按比例削减各槽位的配额，不会出现"前面那种材料把算力吃光"的情况。

### 耗电

**本 MOD 不改变物流塔的耗电**，塔的功率与原版完全一致。

算力**结余不结转**：一帧花不完的算力直接作废。
唯一的例外是"本帧算力买不起 1 个矩阵"的情况——这时会把零头攒起来，凑够 1 个矩阵再扣
（进度上限就是 1 个矩阵，不会囤积算力）。所以等效吞吐恒等于 `U×Y` 点/帧。
把配置项 `AccumulatePartialPoints` 设为 `false` 就变成严格按本帧算力结算——注意此时若
`U×Y` 小于第 1 格矩阵的单价，就会永远兑换不出东西。

> 为什么需要这个零头累积：默认 `U=100`、`Y=100%` 时每帧只有 100 点算力，
> 而引力矩阵单价 1500 点、宇宙矩阵 3000 点。若严格按本帧算力结算，这两种矩阵永远买不起 1 个。

### 举例

- `U=100`、`Y=100%`、`X=1`：每种材料每帧 100 点，折合每秒 6000 点。
  - 换能量碎片（50/个）：120 个/秒（塔里放 3 种材料就是每种各 120 个/秒）
  - 换核心素（300/个）：20 个/秒
- `X=10`（策划案里的例子）：1 个电磁矩阵（50 点）只能换 10/10 = 1 个能量碎片。
- `Y=1100%`（研究速度 10 级）：每帧 1100 点，折合每秒 66000 点。

## 配置

第一次进游戏后在 `BepInEx\config\TTenYX.DSP.DarkFogWorkshop.cfg` 生成，全部数值都可改：

| 分区 | 配置项 | 说明 |
|---|---|---|
| 1. 通用 | `ExchangeFactor` | 兑换系数 X，可小数、必须 > 0 |
| | `MatrixPointPerFrame` | 物流塔每帧算力 U，正整数 |
| | `TechSpeedPercent` | 科技研究速度 Y 的默认百分比 |
| | `UseGameTechSpeed` | `true` 时 Y 自动取存档的科技研究速度 |
| | `SpeedMultiplier` | 调试倍率，默认 1 |
| | `AccumulatePartialPoints` | 每帧算力买不起 1 个矩阵时是否攒零头，默认开 |
| | `OutputSlotLimit` | 参与兑换的材料槽位上限，默认 4 |

| 3. 科学矩阵算力 | 六种矩阵各一项 | 正整数 |
| 4. 黑雾材料算力 | 六种材料各一项 | 正整数 |
| 5. 界面 | `AutoRenameStation` | 是否启用自动改名，默认开；改成 `false` 即完全不动塔名 |
| | `StationName` | 自动改名写入的名字，默认「黑雾工坊」，可自定义 |
| | `LogActivation` | 自动改名等动作写入 BepInEx 日志 |
| | `DiagnosticLog` | 兑换判定过程写入日志（排查"不兑换"用），默认开 |

## 界面

- 满足条件且**新增了一种黑雾材料**时，会自动把塔名改成 **黑雾工坊**（只在新增材料时检测一次）。
  如果塔名已经是玩家自己起的名字，则视为已改名，此后不再自动改。配置项 `AutoRenameStation` 可关闭。
- 窗口标题栏**关闭按钮的正下方**有一个 **`?` 提示控件**（克隆游戏原生的提示控件，做法参考 UXAssist），只在满足三项条件时出现。
- 鼠标悬停会弹出提示：**标题为 `黑雾工坊DarkFogWorkshop`**，内容依次是
  第 1 格物品的单位算力与消耗速度（每分钟）、各材料槽位的单位算力与生成速度（每分钟），
  最后附上科学矩阵与黑雾材料的算力表。
- 它**不是按钮**：点击没有任何反应，不会弹出白色说明文字；也不会在启停时弹提示。

## 兼容性

- 与"运输塔扩容"类 MOD 兼容：判断只看第 1 格与第 2/3/4 格，更多格子不受影响。
- 消耗/产出都会计入统计面板的生产与消耗。
- 只有**第 1 格**被设为本地需求、且里面是科学矩阵时才会触发，不会误伤普通的星际塔（星际塔的第 5 格是翘曲器，与这里无关）。

## 编译

```powershell
dotnet build 'DSP-DarkFogWorkshop\DarkFogWorkshop.csproj' -c Release
```

- 目标框架 `netstandard2.1`，产物 `bin\Release\netstandard2.1\DarkFogWorkshop.dll`。
- 依赖 `DysonSphereProgram.GameLibs` 0.10.35.29088-r.0，游戏本体无需安装即可编译。
- 编译后会自动部署到 profile `0.10.35 new`（游戏运行中会部署失败，关掉游戏重新编译即可）。
