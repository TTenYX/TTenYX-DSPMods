# 分拣器失效：已修复（游戏内确认）

**结论（用户实测确认）**：`v11.X` 包内的 `37.5小火箭 （需求氘棒）` 原件，用 BPT 现版（73728 字节）省带后重新粘贴，**分拣器零失效** ✓。

## 证据链

1. 用户保存的"省带后"文件：分拣器 **空端 0、悬空 0** → 失效不是连接丢失，是**游戏拒绝已存连接**。
2. A/B 对照（同蓝图同位置，只切换 `Belt/RebindSorterLinks`）：
   - 开：**8 处**失效；
   - 关：**3 处**失效。
   → 两类成因：① 引用被改指（+5 处）；② 合并改变分拣器所依附那一节带的几何（3 处）。
3. 被证伪的判据：
   - `PlanetFactory.cs:5865` 的 1.414 m 窗口是**连接缺失时**的就近接上逻辑，不是已存连接的判据（按它预测 62~94 处，与实际数量级不符）；
   - 用「节点连线（弦）」量距离会高估：真实路径是**贝塞尔曲线**（系数 0.552~0.667，由前后节点角度决定）。
   → `BeltWindowRepair.cs`（补点）**停用**，代码保留备查；贝塞尔路径模型保留在 `BeltPathGeometry.cs`。

## 修复实现（当前 BPT 73728 字节）

1. **引用不改指**：被引用的带节点一律固定，`重绑附属连接 0` 处；
2. **定点保护三点**：该节点 + 后继 + 前驱（分拣器总依附在一节带的**起始处**，实测投影 `t≈0`，该处贝塞尔控制点只依赖这三点）→ 局部路径与合并前一致；
3. 事后仍逐个端点判定/重绑（原件上仅修正 4 处），保证空端 0、悬空 0。
