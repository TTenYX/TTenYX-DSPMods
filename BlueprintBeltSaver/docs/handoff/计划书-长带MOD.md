# 计划书：BlueprintBeltSaver（蓝图长带化 MOD）

> 姊妹篇：《交接书-长带MOD总纲.md》（记录已发生的事实）；本文记录**基准准则与待办计划**。任何改动先对照 §0 准则。

## 0 基准准则（玩家 2026-10-18 定稿，最高优先级）

1. **带距准则**：长带化不可出现传送带过长或过短导致无法粘贴。
2. **分拣器准则**：长带化不可出现分拣器失效，包括但不限于输入端失效、输出端失效。
3. **喷涂机准则**：长带化不可出现喷涂机失效，包括但不限于原料带失效、增产剂输入带失效。
4. **总体准则**：不可出现其他任何可能让蓝图失去原有工作状态的情况。
5. **碰撞准则（2026-10-18 新增）**：带节点间有电线杆时，长带化后传送带不得与电线杆碰撞（合并跨度避开杆周 0.6 赤道格，阈值可按建筑尺寸调整）。

**执行口径**（怎么算"没违反"）：
- 离线验证矩阵全绿后才允许部署：模式 {格点、插值、双模式取优采纳（复刻插件 TryOptimize 真实流程）} × 纬度 {0.5°, 30°, 35°, 40°, 45°, 72°} × 样本蓝图全集合（可燃冰/C1绿糖/16.4小火箭/刺笋/三糖/带上分拣器/80环带），四准则零违反（越限链节 0、空端 0、悬空 0、分拣器臂长守卫零违规、建造顺序违例 0）。
- 每次部署前在 BPT 目录留当版 DLL 备份（命名含版本+哈希），保证一键回滚。
- **矩阵已落地（2026-10-19）**：`.work\belt-regression\MatrixRunner.cs`，命令
  `Checks --matrix .work\belt-regression\matrix-list.txt <cap>`（样本 12 张，含 6k/极地/37.5/2880/1440；

  库内 72° 先省带，再逐纬度复刻"增量复核 → 越限则从真原件重省"，断言最终在该纬度
  非原件越限 0、悬空 0、空端 0、带数 ≤ 原件。部署 004.9 前 cap 1.9 / 2.3 各 **72/72 PASS**。
