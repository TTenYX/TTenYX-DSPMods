**执行口径（部署前必须全绿）**：
- 离线矩阵：模式 {格点、插值、双模式取优采纳} × 纬度 {0.5,30,35,40,45,72}° × 14 张测试蓝图，
  断言四准则零违反 + 闸门越限新链节 0 + 带数不净增。当前权威基准 = **suite-v8-全姿态包络**（`.work/belt-regression/`）。
- 流程矩阵（`--flow`）：库内省→拖纬度→增量复核→越限从真原件重省，各纬度（吸附到最近合法姿态）断言非原件越限 0。
- 全姿态审计（`tools/abprobe --pasteaudit`）：原件、蓝图A（TEST 口径与出厂默认配置两份）、蓝图B 全部 PASS。
- 断链审计（`--droplink`）：游戏同式 × 全合法姿态越限 0。
- 附加机普查（`--addons`）：TEST 口径与出厂默认配置两条路径，有带连接口全部保持原最近节点。
- IL/夹具校验（bb-saver-check）：ALL CHECKS PASSED。
- 游戏内自测（tools/selftest，干净环境）：全部检查 PASS + 14 张蓝图B 导出成功。
- A/B 语义对比（`--semdiff`）：全部配对 SEMANTIC-IDENTICAL。
- 部署：备份 `.bak-<时间戳>` → 覆盖 → SHA256 一致 → DLL 内 grep 新符号。
