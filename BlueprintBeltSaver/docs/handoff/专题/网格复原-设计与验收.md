# 网格复原：设计与验收

> 2026-11-05。适用于 BlueprintBeltSaver 新增的「复原」功能。它是现有长带化的反向重采样，不是原蓝图备份恢复，也不依赖省带前快照。对外版本号仍保持 1.0.4，发布前另行确认。

## 功能边界

「复原」沿当前线路的平直经纬网格方向补回一格步进的节点，移除能够安全替换的非网格插值点。新增节点的 X/Y 为整数，不按固定米数均匀分段。线路端点、转角、坡道、等级切换、信号和标签，以及分拣器、喷涂机、流速监测器、带供弹炮塔的连接窗口原样保留。强行移动这些点可能改变工作状态，因此默认只调整安全部分。

单张蓝图的数据并不能反推出全部已删除的原节点。「复原」不会声称恢复了未知原蓝图，也不会直接把历史快照覆盖回去。

## 配置

| 配置项 | 默认 | 含义 |
|---|---|---|
| `Belt/RestoreQuantizeHeight` | `true` | 复原节点高度采用 0.5 的倍数。无法安全量化的连接点和坡道等保留。关闭时保留原高度，但带距校验仍执行。 |
| `Belt/RestoreStrictGrid` | `false` | 关闭时安全部分复原，提示仍不符合网格要求的保留节点及其编号、区域、坐标；开启时全部传送带 X/Y 必须为整数，高度按上一项检查，存在冲突则整张蓝图不应用。 |

这两项不影响原有省带的合并上限、分拣器重绑和徒手拉带设置。「复原」也不允许通过关闭省带侧的跨纬度安全或最短距离限制来绕过自己的安全检查。

## 按钮和确认流程

「复原」位于「省带」左侧，与省带按钮同尺寸，以变换后的屏幕边界留出 10 px 间隙。按钮跟随库内、复制和粘贴窗口的实例切换重新创建，蓝图为空或原有操作不可用时禁用；语言随游戏切换。

点击后只进行独占副本上的试算。确认框显示前后节点数、新增数、移除数、已复原/受保护/未调整区段以及保留点明细。弹窗最多显示 12 个保留点；完整坐标报告写入 TEST 的 `BepInEx/config/BlueprintBeltSaver-restore-audit/`，每次使用唯一文件名，报告路径在弹窗和日志中显示。取消不回写。确认期间蓝图、窗口、建筑数组或复原配置发生变化时，旧候选失效，必须重新点击。

应用时保留窗口持有的蓝图对象，更新节点数组、刷新窗口、写入剪贴板并在实际粘贴工具可用时同步。只移除独立的 `BBSOPT=1` 扩展字段，不删除其他字段；同时清除旧省带快照、跨度缓存和位置键，避免复原结果又被自动省带覆盖。

## 安全检查

1. **纬度网格**：按原件合法且能干净粘贴的全部姿态建立 `PasteEnvelope`。候选节点所在纬度的真实经度网格宽度必须与所属区域参考网格相符；多区域整圈蓝图中超出记录区域的部分不假称为原生网格，保留不变。
2. **带距**：新跨度须满足全姿态最大距离以及逐姿态最短距离检查。端点附近不足最小间距的网格点不生成，不使用碎片短带；不能同时满足网格与带距时保留该区段。
3. **线路拓扑**：每条原线路与结果线路一一对应。将新增链节收缩、移除点穿透后，带的有向连接、端点、分叉和汇流仍与输入一致。不得靠几何最近点把不同线路连接起来。
4. **设备连接**：所有非带建筑的取/放目标不改指；连接窗口及其塑形邻域保持。新增节点不得抢占附加机自动接带窗口。
5. **碰撞**：新增节点检查内嵌建筑碰撞盒及其他线路的节点、线段距离。检测到风险则保留原区段。
6. **原版标准化**：在调用 `CheckBuildingData` 前分配最终数组索引。原版会删除索引不匹配的节点，而非自动补全索引。标准化前后均检查拓扑，并对序列化回读的引用再次核对。
7. **预算**：沿用现有 15000 建筑预算；复原允许净增带，但不允许突破安全预算。

## 自动化测试入口

在仓库根目录 `1.我的MOD` 执行：

```bash
dotnet build BlueprintBeltSaver/BlueprintBeltSaver.csproj -c Release -t:Rebuild
dotnet build BlueprintBeltSaver/tools/restorecheck/RestoreCheck.csproj -c Release
dotnet BlueprintBeltSaver/tools/restorecheck/bin/Release/net8.0/RestoreCheck.dll --all --out BlueprintBeltSaver/tools/restorecheck/reports/all.txt
bash BlueprintBeltSaver/tools/run-restoration-regression.sh
dotnet build BlueprintBeltSaver/tools/selftest/BBSaver.SelfTest.csproj -c Release -t:Rebuild
powershell -NoProfile -ExecutionPolicy Bypass -File BlueprintBeltSaver/tools/run-restoration-selftest.ps1
```

独立离线测试不链接生产源码，通过反射调用构建 DLL，另行验证全部源字段不变、完整头部保留、有向拓扑、设备目标、节点元数据、逐姿态带距、重复复原和序列化往返。还用人为串线、环路切断、同线改指等反例证明验收器能识别错误，不能仅凭线路数量相等判定正确。

省带回归写入独立的 `tools/restorecheck/reports/saving-regression/`，不覆盖第九轮基线。游戏内脚本仅管理自己启动的进程，临时移出其他插件，结束后删掉 `RUN_TESTS`、移除自测插件并还原原插件目录；失败时恢复部署前 DLL。游戏内报告写入 `tools/restorecheck/reports/ingame-<时间戳>/`。
