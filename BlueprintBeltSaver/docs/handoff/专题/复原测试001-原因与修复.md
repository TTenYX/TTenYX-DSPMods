# 复原测试用例001：原因与修复

> 2026-11-05。样本为用户提供的 [复原测试用例001.txt](<D:/Game/DSP/Dyson Sphere Program/Blueprint/复原测试用例001.txt>)。原件不覆盖；回归夹具按字节复制到 [restore-case001-source.txt](<../data/restore-case001-source.txt>)。

## 原件实际内容

游戏解析器与独立 GZip/Binary 解析一致：13 个同级传送带节点，1 条线路，无分拣器或机器引用；有向连接为 `12→11→…→0`，所有 `inputObj` 为空，这仍是一条有效的单向连接链，不能误判成断链。

区域为 15×1，区段数 200。中间五个节点的 X 为 11.6668、10.3335、7.6668、6.3334、3.6667，属于长带化插值点。其余接近整数的 X 误差不超过 0.0001174 格，Y 误差不超过 0.0000208 格，Z 误差不超过 0.0001008 层。

节点 11 有原始标记参数 `[1001,360]`，位置约 `(1.000082,0.00002075,0.00010071)`。它不是没有标记的普通节点，必须保留标记，不能将全部中间节点一刀切删除。

## 旧版真正阻断点

旧版并非因为该线路不是直线而拒绝。12 条原始边均通过平直轴判定，实际存在端点和标记锚点；短的 `12→11` 区段无需调整，长的 `11→…→0` 区段被保留。

问题在原件姿态保护集：旧 `PasteEnvelope.Build` 只用最大距离判断原件是否「全净」。单行蓝图允许区域包围盒位于极点，因而保留了原件在 ±90° 和 ±89.64° 已重叠或过短的 8 个姿态。

| 源件姿态 | 源件最短链节 | 源件最长链节 |
|---|---|---|
| yaw 0 / 纬度 −90° | 约 0.00000274 m | 约 0.000139 m |
| yaw 0 / 纬度 −89.64° | 约 0.262934 m | 约 0.522951 m |
| yaw 0 / 纬度 +89.64° | 约 0.262929 m | 约 0.522931 m |
| yaw 0 / 纬度 +90° | 约 0.00000274 m | 约 0.000137 m |
| yaw 180 | 与上述对称 | 与上述对称 |

这些原件已经不满足最短带距，却被用于要求新节点在所有姿态下安全。旧算法因此删除全部 7 个新格点：12、11、10、8、7、6、4；剩下的 3→5 跨度约 3.147 m，5→9、9→13 跨度约 6.217 m，又触发最大距离拒绝。结果为 13→13，区段完全未复原。

另一层问题是把「在误差容差内」当成了「字面整数」：默认非严格模式保留了接近整数的端点和标记节点，所以即使长区段恢复成功，坐标仍可能出现 1.000082 等值。

## 修复策略

1. 新增复原专用 `BuildForRestoration`：根据不可变原件的实际最短和最长链节筛选工作姿态，1532 个最大距离合格姿态中排除 8 个原件已经过短的姿态，保留 1524 个。省带继续使用原来的 `Build`，不改变其验收口径。完全没有工作姿态时保留旧保护集作保守回退，不能以空集合让候选真空通过。
2. 不放大 0.0002 容差。仅对未绑定、非分叉、同区同级且无附加机窗口冲突的组件，在独占副本上提出原子规范化候选：接近整数的坐标和接近半层的高度取其精确值。三分之一插值 X 不取整，交给路径重建。标记参数、引用和节点身份原样保留。
3. 优先调用真实的 `PlanetGrid.SnapLineNonAlloc` 生成经纬网格路径候选，在格点经度参考系中生成后反投影回蓝图区域，检查其 X/Y 确实为整数。原生规划不适用时继续走既有安全重采样回退，不先删除原图。
4. 规范化原节点后，其关联跨度视为几何新跨度，不能仅凭对象身份继承原件跨度豁免。最终结果和序列化回读均重新检查最大和最小距离、拓扑、元数据、碰撞和其他线路距离。
5. 默认保留点统计改为字面整数判定。严格模式不再盲目取整受保护节点，而是存在无法安全满足条件的节点时整体拒绝。

## 采纳原生规划的范围

用户提出的「删除中间节点、按原生路径重建，再绑定交互建筑」已采纳其**原生规划候选**思路。实际实现不先破坏原件，也未启用整图删除后自动吸附近设备的做法。

经纬平直区段可以用原生规划替换内部节点；分拣器/机器目标、喷涂机/监测器/炮塔接带窗口仍优先保留。喷涂机靠几何窗口自动接带，不能直接套分拣器引用重绑。扩大设备重绑范围需要独立的同线路目标和原生接带验证，不能以最近节点搜索替代。当前样本没有设备引用，因此可以全部满足坐标条件，而不牺牲这些安全准则。
