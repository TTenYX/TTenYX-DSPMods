## 2. 本轮技术改动

1. **长度模型改为查"纬度带表"（关键修复）**
   - 蓝图坐标单位是"格"；一格经度弧长 = 1.2566 m × 该带格宽系数。
   - `areaSegments × 5` = 该带沿纬线格数 → 定位纬度带（200→1000 格/圈 = 第一纬度带/赤道 … 4→20 格/圈 = 第十二纬度带/极点）。
   - 格宽系数取带下边界值（1.0/1.092/1.134/1.115/1.052/1.112/1.216/1.137/1.198/1.107/1.430/1.291）→ 任何跨度都是上界；纬度方向恒 1.2566 m/格；高度 1.3333 m/格 + 海拔半径放大。
   - 用"蓝图自身原始链节"做上界校准（合法蓝图必然不超过 2.3022 m 硬上限）。
   - 踩坑：不得在带系数之外再按节点 y 偏移折算纬度（区域锚点本就在该带纬度上，重复折算使极地跨度放大 2.6 倍）。
2. **撤销"失效连接断点"守卫**：极地图 144/415 条存储连接几何超限（游戏粘贴时会重算），误判导致收益归零；合法性改由模型+校准+逐段复检保证。
3. **重绑偏移守卫**：分拣器抓放目标是目标带"中心 buffer"（1 buffer ≈ 0.06 m），合并移动段中心后，仅在确定越界时夹取 offset。
4. **合并策略**：保点模式（只用原节点）优先；保点省 0 时自动插值重试，仅更省才采用（弹窗与日志标注所用方式）。
5. 早期修复：设置窗口掉帧（每帧反射/GUIStyle 分配/Text 赋值）、面板实例切换导致按钮消失、崩溃防护补丁、按钮改为"省带"、确认窗改用游戏原生 `UIMessageBox`（含物品富文本图标）。
