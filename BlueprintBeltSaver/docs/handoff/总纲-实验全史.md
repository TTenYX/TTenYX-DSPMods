## 0 基准准则（2026-10-18 玩家定稿，所有改动的最高优先级；细则见《准则与待办.md》）

1. **带距准则**：长带化不可出现传送带过长或过短导致无法粘贴。
2. **分拣器准则**：长带化不可出现分拣器失效，包括但不限于输入端失效、输出端失效。
3. **喷涂机准则**：长带化不可出现喷涂机失效，包括但不限于原料带失效、增产剂输入带失效。
4. **总体准则**：不可出现其他任何可能让蓝图失去原有工作状态的情况。
5. **碰撞准则（2026-10-18 新增）**：传送带节点连接之间有电线杆时，长带化后传送带不得与电线杆碰撞——合并跨度不进入电线杆周围 0.6 赤道格（0.75 m；玩家提议 0.5 档，按杆半径~0.35+带半宽~0.2+余量微调，可按建筑尺寸调整）。

## 0. 一句话目标

给《戴森球计划》(DSP 0.10.35.29088) 的 BepInEx MOD **BlueprintBeltSaver** 做"蓝图传送带长带化（省带）"：合并相邻传送带节点以减少建筑数，**同时保证省带后的蓝图能正常粘贴、分拣器全部正常工作、且不卡顿**。

## 1. 铁律（最高优先级，玩家明确下达，不得违反）

1. **省带后的蓝图绝不允许出现"过长而无法粘贴"的传送带**，尤其是**跨多纬度带的大蓝图**；
2. **绝不允许出现分拣器失效**（游戏提示「输入端失效 / 输出端失效」）；
3. 在前两条成立的前提下，**省带量尽量大**、**不得引入卡顿**。
   - 玩家原话："让你保证不是让你消极怠工" —— **禁止**用"省 0 / 拒绝合并"换安全；安全必须靠**算准**实现。

## 3. v3 的技术方案（核心）

**按"本次实际粘贴位置"精确建模，一次算清；彻底删除姿态枚举。**

1. `BeltSpacingCalibration.cs` 重写为**单点位置精确模型**：输入 = 粘贴工具给出的**锚点纬度 + 偏航象限**，逐节点算真实几何。
   - 一格 x 的弧长按**该节点自己的纬度**查游戏分段表，并**沿 x 积分**（0.25 格步长）——游戏是逐节点取值的，不是区域参考纬度、也不是端点值；
   - 只有两点之间积分、**完全不取模**（否则整球图上的接缝会落进相邻节点之间，1 m 被算成 225 m）；
   - 一行等价式：`经度弧长 = 半径 × cos(节点纬度) × 2π /(区域分段×5)`，半径 `= realRadius + 0.2 + z×1.3333`。
2. `BlueprintBeltSaverPlugin.cs`：`ReadPasteObservation()`（读粘贴预览的锚点纬度与 yaw 象限）、`MeasureSavingsAt()`（蓝图库场景试算挑最佳纬度）、`ReoptimizeForPastePosition()`（位置变化 → **0.25 s 节流 + 先 O(链节数) 复核，不过关才从原件快照重算**）、`VerifyHardLimit()`（交付前逐条复核硬上限，有一条越限就放弃省带保留原件）、`SafetyMargin 0.85 → 0.98`、耗时日志。
3. **分拣器安全栈未回退**：引用不改指 + 该节点/后继/前驱三点定点保护 + `InserterBinder` 逐端点判定与重绑。
4. 删除 `Unverifiable → 拒绝合并`（这是上一版"省 0"的直接来源）。

## 3.1 v3.1 增量（2026-10-13 晚，本轮改动）

1. **修 v3 的游戏内自检口径（最重要）**：`VerifyHardLimit` 原来数合并结果里**全部**越限链节。6k太阳帆 的接缝链节是**原件自带**的超限跨度（任何粘贴纬度都量得 214~390 m，见下第 3 条），v3 在游戏里对 6k 会必然报「自检不过 → 放弃省带 → 省 0」，与离线表（用回归台的同跨度感知分析）矛盾。现改为**只统计"新造跨度"**：按原件的 (区域,x,y)→(区域,x,y) 格位跨度建索引（`BuildSpanIndex`），原件里就有的同跨度越限单独记 `KeptOver`，不再触发放弃。契约不变：省带结果对游戏的粘贴结果**绝不差于原件**（原件被拒的那几节带，合不合并同样被拒）。
2. **修拖动快照一次性消费 bug**：`ReoptimizeForPastePosition` 曾在第一次"位置变化→真重算"后把 `_originalSnapshot` 置 null 且不再恢复——之后继续拖动位置，连增量复核都不再执行（入口 null 检查直接返回），越限结果无人拦截。现保留快照，防重入交给 `_lastObservationKey` + 0.25 s 节流。
3. **接缝证据纳入合法性检查（`BeltLinks`）**：同区域内 `|Δx| ≈ 整圈周期 ± 1.6 格` 的带-带对视为"候选相邻"进入证据集。游戏判据是 3D 位置差（经度是角度，sin/cos 自动折叠），x=599.45 与 x=-0.36 在"一圈正好 600 格"的带里就是相邻点；旧 `|Δx|≤1.6` 过滤把这类对全部丢弃，库模式看不到"蓝图在哪些纬度自身就粘不上"。**结论性发现（`--latsweep` 6k）：6k 的接缝节点 y 跨 33.7°，不可能同时落在 600 格/圈的第 3 带，因此 6k 不存在全图合法的粘贴纬度**——`ChooseBestLatitude` 现在正确回退到赤道 0°（最保守兜底，省 227）。极地那张图同理回退 0°（收益本就是 0，无实际影响）。
4. **澄清 §7.5 的错误前提**：`CoreDistance` 最后用 sin/cos 构造 3D 坐标取弦长，经度差本来就按角度周期折叠——"接缝绕整圈不折返"并不存在于生产模型；极地图 226.06 m 的诊断值与折叠模型手算完全吻合。真正的接缝效应是上面第 3 条（坐标周期 ≠ 该纬度一圈格数时，接缝对真实相距很远，游戏同样拒绝）。
5. **§7.6 派生连接已查清**：反编译 `BuildTool_BlueprintPaste` 2083~2098 行——游戏对**每条**带→带存储连接查 `sqrMagnitude > 5.3`（TooFar）+ 陡度；`RefreshBuildPreview` 1541 行把 `outputObj` 原样映射进预览。极地图原件 #470→#469 确实存着 Δx=-5.55 格（任何纬度 ≥5 m）的连接 → **这些"派生连接"是原件自带的断损段，游戏粘贴时本来就会拒绝那几节带**（红色「距离太远」只影响那几节，其余照常放置），不是 MOD 造成的，MOD 也不应为其放弃合并（改动 1 正是为此）。

## 5. 本轮被数据证伪的假设（都发生在实现过程中，务必别再走）

1. "x × 区域参考纬度处格宽"就够 → 游戏用**节点纬度**格宽（6k 上把 1 m 算成 391 m）。
2. "x × 节点纬度处格宽"就够 → 分段表是**量化**的，带边界跳档 → 必须沿 x 积分。
3. "各自积分到节点再取模折返" → 整球图的接缝会落进相邻节点之间（1 m → 225 m）→ 正确做法是**只在两点之间积分、不取模**。
4. 纬度格数用 `Max(0, |纬度/0.36°| − 0.1)` 截断 → 游戏是**取整后取绝对值、没有 −0.1**（南半球 −18.6° 被算成 20 格/圈，实际 1000）。
5. "试算时按空间分块抽稀" → 会整条链删掉、相对收益失真（16.4 从 157 掉到 36）→ 已改为不抽稀。
6. "用几何最保守的纬度当默认值" → 省带量随纬度**强烈非单调**（16.4：76° 省 152、46° 省 0）→ 必须用**实测省带量**当目标函数挑纬度。

历史更早被证伪（仍然有效）：① "1.414 m 路径窗口是已存连接的判据"（那只是缺失连接时的自动接上逻辑，`BeltWindowRepair` 已停用）；② "游戏粘贴时按邻近关系重算整条链路"（反编译证明连接是**原样**拷贝）；③ "把超长存储连接跨越的中间节点全部固定"（链式判定让极地归零、空间判定在 6k 上不触发，均已撤销）；④ "用节点连线（弦）量距离判窗口"（真实路径是贝塞尔曲线）；⑤ "那 47 条模型超长链节"（经度接缝假象，x=599.44→0.12，修正后 1.11 m）。
