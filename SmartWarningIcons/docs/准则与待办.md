# SmartWarningIcons 准则与待办

## 维护准则

- 游戏 0.10.35.29151 的警告图集为 4 列 × 8 行。槽位 `(x, y)` 为 `((signType % 4) * 256, (signType / 4) * 256)`；不要使用早期复盘的 `/8, %8`。保持红色槽 31、黄色槽 25，并确保不覆盖原版 7。以 GPU 像素为准，不从旧试验推导槽位奇偶限制。
- 保留 `GameLogic.OnFactoryFrameEnd` 的单入口和已加载本地工厂限制。制造台和生产模式研究站共用判定：原版停工且已到周期完成线时才显示黄标，不再按缓冲存量预警；一旦恢复生产，即使还有积货也不亮黄标。供电状态和其他原版专用警告优先。研究模式按匹配的科技比较矩阵点数，不判定产物堆砌。
- 矿机池用 `minerCursor`。总量与最小矿点量各调用原版方法刷新，方法须作用于 `ref` 池元素。阈值采用严格小于；不接管抽水机和抽油机。
- 选项中的红、黄开关只影响建筑上方图标；顶部汇总使用建筑自己的警报开关。配置禁用功能与显示开关不等价。
- 对照真机程序集检查成员访问级别，不能仅凭公开化 GameLibs 编译成功判为可用。测试与正式 MOD 分开，发布内容不得包含自测 DLL 或证据目录。

## 待办

- 如需支持其他游戏版本或验证已有大型存档，用明确的游戏版本和存档副本补测。当前测试不证明和所有第三方 MOD 兼容。
- 不与 BetterWarningIcons 同时安装。本轮不修改上游仓库和 PR #34，不处理上游许可证。
- 2026-11-20 已按用户确认以 `1.0.0` 发布到 Thunderstore；版本号不可复用，后续更新需提升版本并让用户确认。
