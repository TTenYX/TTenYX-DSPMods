# 更新日志 / Changelog

## 0.2.0

首个正式版本。

- 功能 1：小型/大型储物仓「自动化输入限制」拉到 0 时消耗所有输入物品（手动放入、Ctrl 快速入库、分拣器、开采器/无人机、传送带末端与四向分流器落料）；输入限制 > 0 立即恢复普通收纳。
- 功能 1：储液罐「输入」开关设为关时，消耗所有经传送带和手动注入的液体（只消耗液体类物品；罐内已有存量不动）。
- 功能 2：传送带图标标签 SIGNAL-404 消耗经过物品；标签数量 0 为全部消耗，N 为每统计周期 N 个（周期默认 60 秒，可配置；按物品个数计、整堆扣减）。
- 消耗量计入产量统计「消耗」。
- 全部开关与统计周期可在 cfg 中调整并热生效。
- 无需任何前置 MOD，不写入额外存档数据。
